# Data Science Lab Experiment 01

## Experiment
Exploring CSV Dataset using Python and Pandas

## Dataset
ex2data1.csv

## Tools Used
- Google Colab
- Python
- Pandas
- GitHub

## Exploratory Data Analysis (EDA)

The following analysis was performed:
- Loaded the dataset using Pandas.
- Displayed the first five rows using `head()`.
- Examined the dataset structure using `info()`.
- Generated summary statistics using `describe()`.
- Checked for missing values using `isnull().sum()`.

## Conclusion

The dataset was successfully loaded and analyzed using Python and Pandas. The dataset structure, statistical summary, and missing value analysis were performed successfully, providing an overview of the data for further analysis and machine learning tasks.
